## 3.20　图片不显示的三类成因与排查路径

3.20.1　先分清三类再动手
网站上线后出现「图片不显示」，有三条独立的成因路径。它们的表象相似，但解法完全不同，用错解法会白折腾——例如成因二其实不是配置问题，改 PHP 代码并不能解决。
判断入口是「谁看不到」：
自己和海外访客都看不到 → 优先查图片引用方式与图床可达性（成因一、成因三）。
自己能看到、海外访客看不到 → 优先查访客 IP 定位（成因二）。
只有部分图不显示 → 优先查单个链接是否失效。
3.20.2　成因一：PHP 站点用服务器 IP 展示图片
在使用 PHP 编写网站时经常遇到图片不显示。这是因为 PHP 网站默认使用服务器的 IP 地址来显示图片，而服务器的 IP 地址往往不能直接访问，所以图片不显示。
两条解法：
解法 A（推荐）：使用第三方图片服务器托管图片，把所有图片改为外链绝对地址。
解法 B：修改 PHP 代码，改为输出可公网访问的图片地址而非服务器 IP。

## 3.20　图片不显示的三类成因与排查路径

3.20.3　成因二：访客 IP 被定位到国内
一般来说，国外的 IP 地址访问网站不会显示图片。这是因为网站服务器会把图片信息发送到国外的 IP 地址，而这个地址并不存在。
处置分三步：
1. 第一步：先查明需要访问的国外 IP 地址段。
2. 第二步：使用 IP 地址定位的方法来访问网站，服务器就会根据你的定位自动将图片信息发送到国内的 IP 地址——这只是让你自己能看到，是排查手段不是修复手段。
3. 第三步（真正的解法）：使用国外的 IP 网络，让访问者直接通过国外 IP 访问你的网站，从而解决图片不显示的问题。

## 3.20　图片不显示的三类成因与排查路径

3.20.4　成因三：图床或外链本身不可达
网络上图片不显示是很常见的问题，特别是当网站访问者来自国外的时候。对应的处置是把图片全部落到自有可控的存储上。
这也正是发布清单第 2 条「在线文档工具图片下载后重传」要解决的问题：在线文档工具链接不是公网可访问的图床，直接引用必然失效，下载后重传到自有存储才是稳定状态。
判断依据是链接本身：把图片地址贴到浏览器地址栏直接打开，打不开就是这一类；能打开但网页里不显示，看 19.2 与 19.5。

## 4.32　建站起步：域名、程序、服务器怎么定

📖 本章速览　建站顺序不能反：先定域名与服务器 → 再选建站程序 → 再挖关键词建词库、定导航与标题 → 最后才动手搭建。域名要短、要贴主题、后缀选主流；程序按站点类型选开源；服务器与域名要匹配站点规模。

## 4.33　收录与索引：收录了却没排名怎么查

📖 本章速览　收录 ≠ 有效索引，更 ≠ 排名。判断是否建立有效索引的土办法：把页面完整标题复制去搜索，能搜到即已建索引；搜不到就是没建索引，谈不上参与排名。

## 4.34　链接体系：友链、反链、外链、内链到底是什么

📖 本章速览　四个概念一次说清：外链与反链是「别人链我」，友链是「互相链」，内链是「我链我」。友链必须能在网页代码里找到网址和网站名称、浏览时能显示网站名称，才算友情链接。

## 4.35　权重与排名：权重怎么算、为什么会掉

📖 本章速览　权重是针对前 50 名关键词排名预估流量来计算的：关键词数量越多、排名越靠前、搜索量与指数越高，预估流量越多，权重就越高。所以权重掉了，先查那批词的排名波动，而不是先怀疑服务器。
